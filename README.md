# EMNIST Handwritten Character Recognition

Pipeline: Improved PCA + PCA + RPCA Forest + KNN

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python main.py
```

EMNIST tự download lần đầu (~500MB vào thư mục `data/`).
